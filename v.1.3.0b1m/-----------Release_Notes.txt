NEW UTILITIES
----------------------------------------------------------------

No new numbered utilities. All 21 utilities from v1.2.5b1m are
present (slots 1-21); Exit remains slot 22. The major addition is
a graphical hub and embedded tool sessions.

----------------------------------------------------------------
HUB CHANGES
----------------------------------------------------------------

  - Graphical hub added (RandomUtilitiesGUI.cpp). The default
    Windows build opens a GDI+ window with:

      - 4-column tile grid for tools 1-21 and Exit [22]
      - live search bar with substring, keyword, and Levenshtein
        fuzzy matching
      - per-tile hover tooltips with full name and description
      - status bar (version, session time, launch count)
      - About/System Info dialog (F1 or System Info tile)
      - Exit dialog with "Exit this window", "Exit all windows",
        and "Cancel"
      - optional logo.png branding in the header, About dialog,
        and window icons

  - Classic console hub still available:

      --cli, -c, /cli   launch the old text hub
      --tool N          run tool N in a console window and exit
                        when it finishes

  - Tools run embedded in the main window by default. Each tool
    is a "session": a worker thread plus a text buffer drawn into
    the pane. A session can be:

      - moved to a sub-window ("Sub-window")
      - moved back into the hub ("Open in Graphics")
      - launched as a separate console process ("Open in CLI")
      - closed from the hub or sub-window

  - New IConsoleHost interface (RandomUtilities.h). When non-null,
    clearScreen, pause, getHiddenPassword, getAdvancedInput,
    getAdvancedInputWithNav, RAM Query watch-mode keys, and Quick
    Note editor I/O are routed to the GUI session instead of the
    real Win32 console.

  - Session I/O redirection: per-thread std::cout, std::cerr, and
    std::cin are routed to the session''s buffer and input queue.
    CLI mode leaves these pointers null, so the old console
    behaviour is unchanged.

  - New ANSI handling in the GUI pane: SGR colours (30-37,
    90-97, 40-47, 100-107, 38/48 5/2), bold, underline, reset,
    clear-screen, and a caret marker ESC [ z.

  - ConfigureConsole now enables
    ENABLE_VIRTUAL_TERMINAL_PROCESSING on the Windows console
    output handle, so ANSI colour swatches and styled output work
    in modern consoles.

  - Removed agent logging and the RANDOMUTIL_DEBUG_TEST self-test
    path from RandomUtilities.cpp.

----------------------------------------------------------------
NEW FEATURES / TOOL CHANGES
----------------------------------------------------------------

[14] Quick Note
     Embedded GUI editor added. In the graphical hub, Quick Note
     now has:

       - plain-text editing with caret marker
       - Markdown preview (F2, or :md / :plain)
       - scrolling in preview (Up/Down, PgUp/PgDn, Home/End)
       - :wq, :q, :d, :pass commands
       - password set/clear from the editor

     The CLI editor and the non-Windows fallback keep the previous
     behaviour. File format is unchanged.

[19] File Hasher
     CRC32 and SHA-256 now stream the file in 64 KiB chunks.
     Large files no longer need to be loaded into memory as one
     string. File size is read with std::filesystem::file_size.

[20] Secure File Mover
     - SHA-256 verification now uses the streaming file hasher.
     - Source and destination paths are sanitised: leading/trailing
       spaces are trimmed, matching single or double quotes are
       stripped, and a leading ~ expands to USERPROFILE or HOME.
     - Destination folders are created per file from the relative
       path. The old up-front destination creation was removed.
     - The error-tolerant manual walk and deepest-first empty-folder
       cleanup are retained.

[21] RAM Query
     - Watch mode is disabled when RAM Query is embedded in the
       GUI hub. It prints a notice to launch with --cli instead.
     - Watch mode uses the console host key queue when available,
       so embedded sessions do not freeze on _kbhit/_getch.

[17] Prime / Factor Tools
     - isPrimeLL and factorizeLL now refuse values above 10^15
       (kPrimeToolLimit) to avoid long trial-division stalls.
     - Note: PrimeToolsPr does not currently warn before calling
       them, so values above 10^15 may be reported as "not prime"
       or with no factors. See Known Limitations.

----------------------------------------------------------------
BUG FIXES
----------------------------------------------------------------

  - File Hasher: large files no longer cause high memory use or
    failed reads due to loading the whole file into a std::string.

  - Secure File Mover: path input with quotes, trailing spaces, or
    ~ now works correctly.

  - RAM Query: embedded watch mode no longer calls _kbhit/_getch
    on a GUI session, which previously could block or misbehave.

  - ConfigureConsole: ANSI escape sequences are now enabled for
    console output, so Color Converter swatches and other styled
    output render correctly.

  - Removed debug logging writes to debug-f62c21.log from normal
    operation.

FILE FORMAT
----------------------------------------------------------------

  Quick Note - plain text file:
      <body>

  Quick Note - encrypted file (v1.2.5b1m and later):
      SHIVANSH_V1\n                       <- plaintext header
      XOR(SHIVANSH_V1\n<body>, password)  <- encrypted payload

  No file-format changes in v1.3.0b1m. Markdown preview is read-only
  and does not alter the saved file format.

----------------------------------------------------------------
KNOWN LIMITATIONS
----------------------------------------------------------------

  - Prime / Factor Tools: values above 10^15 are silently treated
    as not prime and factorise to nothing. A future revision will be 
    warned to the user.

  - RAM Query watch mode is not available in the graphical hub.
    Use --cli and select option 14 there. *note
          Note - Currently Fixing this Problem 

  - Quick Note Markdown preview is available only in the embedded
    GUI session. The classic console editor and the POSIX fallback
    do not have :md / :plain preview.

  - The graphical hub is Windows-only (GDI+). Non-Windows builds
    use the console fallback paths.

  - Secure File Mover still does not preserve timestamps or file
    attributes. Wildcard filter still supports only * and ?.

  - RAM Query is Windows-only; POSIX prints a notice and returns.

  - Multi-byte BMP only. Supplementary-plane codepoints are ignored
    on input.

  - Sieve size cap of 1,000,000 in Prime Tools remains deliberate.

  - Color swatch relies on ANSI true-colour support. Windows
    Terminal, cmd.exe on Win 10 1903+, and PowerShell 7 support it.
    Older consoles fall back to no swatch.

  - Logo branding expects logo.png next to the executable or in the
    working directory. If missing, the default Windows icon is used
    and no logo is drawn.

----------------------------------------------------------------
BUILD INSTRUCTIONS
----------------------------------------------------------------

  g++ -std=c++17 RandomUtilities.cpp RandomUtilitiesGUI.cpp -o RandomUtilities -lpsapi -lgdiplus -lgdi32 -luser32

Requires:

  - MinGW-w64 GCC 11+ (or MSVC 2019+)
  - -lpsapi on MinGW for GetProcessMemoryInfo
  - -lgdiplus, -lgdi32, -luser32 for the graphical hub
  - Do NOT pass -municode - the program uses standard main, not
    wmain

Notes:

  - Secure File Mover and File Hasher use std::filesystem, which
    needs C++17 or later. GCC 8 or newer is required.

  - RAM Query uses tlhelp32.h, which ships with MinGW and MSVC.
    No additional link flag is needed; the symbols live in
    kernel32.

  - NtSuspendProcess and NtResumeProcess are resolved at runtime
    from ntdll.dll.

  - The GUI hub uses GDI+. On MinGW link with -lgdiplus; on MSVC
    the pragma comment in RandomUtilitiesGUI.cpp links gdiplus.lib,
    gdi32.lib, and user32.lib.

  - --cli / -c / /cli forces the classic console hub.
  - --tool N runs one tool in a console window.
