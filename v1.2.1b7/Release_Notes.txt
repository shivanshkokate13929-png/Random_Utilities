NEW UTILITIES
----------------------------------------------------------------

[11] Encoder / Decoder
     Base64, URL, Hex, and ROT13/Caesar cipher. Round-trip safe -
     decoded binary is shown with \xNN escaping so nothing mangles
     the console.

[15] Random Picker
     Coin flip, custom dice (sides x count), and uniform
     pick-from-list. Uses mt19937_64 seeded from std::random_device.

[16] Color Converter
     HEX <-> RGB <-> HSL, with an ANSI true-colour swatch preview.
     Accepts #RGB and #RRGGBB, and comma- or space-separated tuples.

[17] Prime / Factor Tools
     Primality test, full prime factorisation with multiplicities,
     next-prime lookup, and a sieve up to 1,000,000.

[18] Roman Numeral Converter
     1 - 3999 both directions, with round-trip validation. Rejects
     IIII, VV, etc.

[19] File Hasher
     CRC32 and SHA-256 for any file, plus size.

EXPANDED UTILITIES

Unit Converter grew from 10 categories / ~80 units to 15 categories
/ ~150 units:

----------------------------------------------------------------
EDITOR IMPROVEMENTS
----------------------------------------------------------------

Quick Note was rewritten as an in-place multi-line editor:

  - Arrow keys move the cursor between lines; nothing reprints
    below the buffer
  - Enter splits a line, Backspace at col 0 joins with the previous,
    Del at end joins with the next
  - Line numbers, live cursor, and "> " current-line marker
  - Optional password protection - auto-detected on load via the
    SHIVANSH_V1 header
  - New :pass command to add, change, or clear a password
    mid-session
  - Plain .txt / .md files open with no password prompt and are
    saved unencrypted - no obfuscation applied
  - Encrypted files write XOR-obfuscated payloads; unencrypted
    files write raw text

----------------------------------------------------------------
BUG FIXES
----------------------------------------------------------------

Console / input engine

  - Ctrl+C now copies the current line to the clipboard instead of
    terminating the process. ENABLE_PROCESSED_INPUT was removed
    from the raw input mode so the KEY_EVENT reaches our handler.

  - Ctrl+V strips newlines before insert, so pasting a multi-line
    block does not corrupt the single-line renderer.

  - Enter / Escape now emit CR+LF rather than bare LF. Previously
    every subsequent std::cout write started mid-line, producing
    the "everything bugged out" cascade after a few keystrokes.

  - pause() drains the input queue via ReadConsoleInputW and waits
    for a genuine Enter key-down. Previously a stale Enter key-up
    from the previous input session caused pause() to return
    instantly, stacking multiple frames.

  - clearScreen() flushes std::cout and std::cerr, then resets the
    visible window to the top of the buffer. Fixes the ghost-text
    overlay ("Press Enter to continue...ed by Shivansh").

  - getAdvancedInput no longer crashes if
    GetConsoleScreenBufferInfo fails - it falls back to plain
    iostream input instead of dividing by zero in
    calculateCursorPosition.

  - ConfigureConsole no longer destroys and recreates the console.
    The old FreeConsole / AllocConsole pair caused the
    flicker-then-vanish behaviour when the process already owned
    a console. Best-effort resize is now in-place and failures
    are ignored.

  - Console codepage is set to UTF-8 - the degree sign in Color
    Converter no longer renders as mojibake.

Quick Note (v1.2.1b7)

  - Password-protected files are now correctly detected on open.
    The SHIVANSH_V1 header is written in PLAINTEXT before the
    encrypted body, so the loader can reliably tell encrypted
    files apart from plain ones.

  - Encrypted files now prompt for a password instead of silently
    loading garbled bytes and (on :wq) overwriting the original
    file with the mangled version.

  - The encrypted payload begins with a second copy of the
    SHIVANSH_V1 marker. On load, this acts as a password check -
    if the decrypted stream does not start with the marker, the
    entered password is wrong and no data is touched.

  - Fixed a stray space before the "Swatch:" label in the Color
    Converter output.

Utilities

  - BMI Calculator saves and restores std::cout flags manually,
    since std::ios has a protected constructor and the previous
    save/restore idiom did not compile.
  - Age Calculator clamps the day-of-month when advancing by
    years/months, so a Feb 29 birthday does not roll over
    incorrectly in non-leap years.
  - readDouble rejects nan and inf via std::isfinite.
  - Prime tools bounds sieve size to 1,000,000 and refuses values
    that would overflow long long.

Hub

  - Exit now waits 3 seconds and prints a proper goodbye before
    closing. Previously the flow returned to the hub's shutdown
    handler on every utility exit because the while (hubRunning)
    loop was missing its closing brace.
  - Menu renumbered: Exit moved from 15 to 20 to free slot 15 for
    Random Picker and slot 11 for Encoder/Decoder.
  - Version string bumped throughout.

----------------------------------------------------------------
FILE FORMAT
----------------------------------------------------------------

  Plain text file:
      <body>

  Encrypted file (v1.2.1b7 and later):
      SHIVANSH_V1\n                       <- plaintext header
      XOR(SHIVANSH_V1\n<body>, password)  <- encrypted payload

  The plaintext SHIVANSH_V1 header signals "this file is encrypted".
  The second SHIVANSH_V1 inside the encrypted payload verifies the
  password.

----------------------------------------------------------------
KNOWN LIMITATIONS
----------------------------------------------------------------

  - XOR obfuscation is NOT encryption. It is a training tool and
    should not be used for anything sensitive.

  - Files written with a password by v1.2.1b3 through v1.2.1b6 are
    unrecoverable. Those versions encrypted the header along with
    the body, and no loader ever read them correctly. Delete and
    re-create them with v1.2.1b7 or later.

  - Quick Note editor is Windows-only in the in-place form. POSIX
    falls back to a line-by-line editor without cursor navigation.
    The data file is identical either way.

  - Multi-byte BMP only. The editor accepts characters up to
    U+FFFF. Supplementary-plane codepoints (emoji, rare CJK) are
    ignored on input.

  - Sieve size cap of 1,000,000 in Prime Tools is deliberate -
    larger values freeze the UI on slower machines.

  - Color swatch relies on ANSI true-colour support. Windows
    Terminal, cmd.exe on Win 10 1903+, and PowerShell 7 all
    support it. Older consoles fall back to no swatch.
